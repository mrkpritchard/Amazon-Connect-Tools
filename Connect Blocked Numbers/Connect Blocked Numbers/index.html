Connect Flow Integration

To use this in your Connect flows, add an Invoke AWS Lambda function block pointing to BlockedNumbers-Check, then check $.External.result.

If result = BLOCKED → Disconnect or play a message. Otherwise the call continues normally. The Lambda auto-detects the Connect region from the instance ARN.

Global blocks (region = "ALL") apply across all Connect instances. Region-specific blocks only apply to calls on that region's instance.
