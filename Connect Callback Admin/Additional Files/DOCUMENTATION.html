Overview

The Callback Admin Portal is a web-based tool for managing Amazon Connect callbacks. It provides administrators with a comprehensive interface to view, manage, and analyze callback data across multiple AWS regions (US and EU).

Key Capabilities

  • View and manage active callbacks in real-time
  • Review callback history with detailed status information
  • Analyze callback data with interactive charts and tables
  • Remove pending callbacks directly from Amazon Connect
  • Export data to CSV or Excel formats
  • Support for multiple timezones and regions

Features

Active Callbacks Management

  • Real-time View: View all pending callbacks with live updates
  • Filtering: Filter by phone number, Contact ID, or Queue name
  • Sorting: Sort columns by clicking column headers
  • Remove Callback: Stop pending callbacks directly via Amazon Connect StopContact API
  • Confirmation Dialog: Safety confirmation before removing callbacks
  • Pagination: Control page size and load more results
  • Timezone Support: View times in your preferred timezone

History View

  • Completed Callbacks: View all completed or deleted callbacks
  • Status Column: See "Completed" or "Deleted" status for each callback
  • Pagination: View 25 items at a time with "Load more" functionality
  • Export: Export all history data to CSV or Excel (includes all items, not just displayed ones)
  • Time in Queue: See how long callbacks waited before completion
  • Linked Contacts: View related contact IDs for callback chains

Analytics View

  • Multiple Chart Types:
    • Bar Chart: Horizontal bar chart showing distribution
    • Pie Chart: Circular chart with percentages
    • Table View: Detailed table with queues/dates, amounts, and percentages
  • Date Range Selection:
    • Today, Yesterday
    • Current Week, Last Week
    • Current Month, Last Month
    • Custom Date Range
  • Queue Selection: Filter analytics by specific queues (multi-select)
  • Date-based Grouping: For week/month views, see dates on x-axis instead of numbers
  • Queue Breakdown: Hover over date bars to see detailed queue breakdown
  • Expandable Table Rows: Click date rows in table view to see queue breakdown
  • Statistics: Total callbacks, average time in queue, selected queues count

Sync Database

  • Manual Sync: "Sync Database" button (formerly "Cleanup Completed")
  • Verification: Checks Amazon Connect to verify callback status
  • Auto-Migration: Moves completed callbacks from active to history table
  • On-Demand: Only runs when button is clicked (no automatic execution on page load)

Active Callbacks View

Removing a Callback

To remove a pending callback:

  1. Locate the callback in the Active Callbacks table
  2. Click the "Remove" button in the Action column (right side)
  3. Confirm the action in the dialog: "Are you sure you want to end this callback?"
  4. Click "Confirm" to proceed or "Cancel" to abort
Important: Removing a callback will:
  • Stop the callback in Amazon Connect using the StopContact API
  • Move the callback to the History table
  • Mark it with status "Deleted"
  • Add a note "Manually removed by admin"
This action cannot be undone.

Filtering and Sorting

  • Use the filter box to search by phone number, Contact ID, or Queue name
  • Click column headers to sort (ascending/descending)
  • Adjust page size to show more or fewer results per page

History View

Viewing History

  • History shows completed and deleted callbacks
  • By default, displays 25 items at a time
  • Use "Load more" to see additional items (loads 25 more each time)
  • Change page size to adjust how many items are displayed initially

Status Column

The Status column shows:

  • "Completed": Callback was successfully completed
  • "Deleted": Callback was manually removed by an admin

Exporting History

Export functionality includes all history items, not just the currently displayed ones:

  • Export CSV: Downloads all history as a CSV file
  • Export Excel: Downloads all history as an Excel (.xlsx) file

Analytics View

Chart Types

Bar Chart

  • Horizontal bar chart showing callback distribution
  • For date-based views (week/month), dates appear on the y-axis
  • Hover over bars to see detailed information
  • For date-grouped charts, hover shows queue breakdown

Pie Chart

  • Circular chart with color-coded segments
  • Shows percentages for each queue or date
  • Legend on the right side

Table View

  • Detailed table showing:
    • Queue / Date: Queue name or date
    • Amount: Number of callbacks
    • Percentage: Percentage of total
  • Sorted by amount (descending) by default
  • For date-grouped views:
    • Click a date row to expand and see queue breakdown
    • Queue breakdown appears directly under the clicked date
    • Click again to collapse
    • Indented rows show individual queue contributions

Date Range Options

Option Description
Today Callbacks from today only
Yesterday Callbacks from yesterday
Current Week Callbacks from the current week (Monday to Sunday)
Last Week Callbacks from the previous week
Current Month Callbacks from the current month
Last Month Callbacks from the previous month
Custom Range Select start and end dates manually

Queue Breakdown on Hover

When viewing date-grouped charts (week/month views):

  • Hover over any bar to see a detailed tooltip
  • Tooltip shows total callbacks for that date
  • Below the total, see breakdown by queue with counts and percentages
  • Queues are sorted by count (highest first)

Configuration

Timezone Selection

The portal supports comprehensive timezone selection with 100+ timezones organized by region:

  • Americas (North, Central, South)
  • Europe
  • Asia
  • Africa
  • Oceania

Timezone preference is saved in browser localStorage and persists across sessions.

Region Selection

The portal supports multiple AWS regions:

  • US (N. Virginia): us-east-1 region
  • EU (Frankfurt): eu-central-1 region

Region selection affects which DynamoDB tables and Connect instances are accessed.

Theme Selection

Toggle between light and dark themes using the theme button in the header. Theme preference is saved in localStorage.

Custom Domain Support

The portal supports custom domain aliases (e.g., https://your-portal-domain.example.com). CORS is configured to allow requests from approved domains while maintaining security.

API Endpoints

Callback Management

Method Endpoint Description
GET /callbacks List active callbacks
GET /callbacks/history List completed/deleted callbacks
POST /callbacks/{id}/stop Stop a pending callback (uses Amazon Connect StopContact API)
POST /callbacks/cleanup Sync database - move completed callbacks to history
DELETE /callbacks/{id} Delete a callback from the active table

Troubleshooting

Common Issues

API Access Issues with Custom Domain

  • Verify CORS is configured in API Gateway
  • Check that the domain is in the allowed origins list
  • Ensure CloudFront (if used) forwards necessary headers
  • Check browser console for CORS errors

Callbacks Not Appearing

  • Verify correct region is selected
  • Check DynamoDB table names match environment variables
  • Ensure user has permissions for the queues being viewed
  • Try refreshing the page

Analytics Not Loading

  • Ensure at least one queue is selected
  • Check date range includes data
  • Verify user has access to selected queues
  • Check browser console for errors

Remove Button Not Working

  • Verify Amazon Connect instance ID is configured
  • Check Lambda has permissions for StopContact API
  • Ensure callback is still in pending state
  • Check browser console for error messages
